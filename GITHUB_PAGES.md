# Free GitHub Pages Setup

Qyrion can be hosted for free with GitHub Pages.

## Recommended Setup

1. Push this repository to GitHub.
2. Go to the repository settings.
3. Open **Pages**.
4. Set the source to **GitHub Actions**.
5. The included workflow publishes the `website/` folder.

## What Gets Published

Only the static website files are published:

- `website/index.html`
- `website/quantum-security-101.html`
- `website/styles.css`
- `website/script.js`

The CLI, generated reports, and planning documents remain in the repository but are not part of the published website.

## Cost

This setup does not require:

- paid hosting
- a paid domain
- a paid database
- paid APIs
- paid AI tools

You can add a custom domain later, but it is not required for a portfolio project.
